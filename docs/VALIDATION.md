# 验证边界

## 已有材料

原模型训练结果、固定模型温度负对照、配对 bootstrap 文件、类别分析、成员比例的标准库重加权复算、研究图版本和项目内策略记录。

## 本仓库检查

运行 `node --test tests/core.test.cjs` 验证基线公式不随阈值变化、复算指标、含并列分数的 AUC、错误图导入、循环安全的候选影响追踪和历史版本保留。运行 `python scripts/reproduce.py` 使用另一语言的标准库核对敏感性结果。

这些测试验证软件与计算，不证明科学普适性、系统效率提升或策略迁移。

## 尚未完成

- 实际遗忘模型与删除后重训模型的比较。
- 新采集独立审计批次。
- 隔离且预算一致的固定流程与策略版对照。
- 真实用户效率评估与跨项目迁移。

候选影响图只表示图关系上的可达对象。断开某条支持边不自动证明论断错误；数据分母、比较条件与科学解释仍需复核。

温度映射的可逆性限定在温度已知、完整正概率输出和足够数值精度的情况下。没有测量校准误差时，不将任意温度变换称为校准改善。
